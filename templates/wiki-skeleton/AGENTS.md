## Read order

What to read for common tasks, in order. One rule is absolute: **anything customer-facing reads [compliance-guardrails.md](compliance-guardrails.md), always.**

| Task | Read, in order |
|---|---|
| Anything customer-facing | `compliance-guardrails` — always, before anything else |
| Writing outbound copy | `compliance-guardrails`, `voice`, `channel-styles` (target channel), `icp-personas` (target persona), `glossary`, `business-core` (approved claims) |
| Blog / long-form content | `compliance-guardrails`, `voice`, `channel-styles` (Blog), `business-core`, `glossary`, `content-assets` (what to link) |
| Competitive or comparison content | `compliance-guardrails` (competitor conduct), `competitors` (+ its battlecards), `business-core` (positioning, right to win), `customers` (proof points) |
| Case studies / social proof | `compliance-guardrails`, `customers` (approval scope), `content-assets` (status), `business-core` (claim wording) |
| Campaign planning | `growth`, `icp-personas`, `product-releases`, `events` (upcoming), `content-assets`, `channel-styles` |
| Reporting on performance | current snapshot, wherever this deployment keeps one — check deployment notes |
